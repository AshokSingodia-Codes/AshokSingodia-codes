## 🚀 Featured projects

### 📈 [FinAdvisor-X: Agentic Hybrid Graph-RAG Financial Intelligence Platform](https://github.com/AshokSingodia-Codes/FinAdvisor-Voice)
LangGraph multi-agent platform for grounded, cited financial Q&A over SEC 10-K filings and finance knowledge bases.
- Hybrid retrieval: Neo4j vector + keyword search fused with Reciprocal Rank Fusion, then reranked by a FlashRank cross-encoder
- Self-RAG verifier checks numbers and citations; deterministic Python calculators (DCF, WACC, NPV, CAGR, SIP) replace LLM arithmetic
- JWT + email OTP auth, per-user isolation tests, multi-provider LLM fallback, evaluation harness (Precision@5, faithfulness, hallucination rate)
- `LangGraph` `Neo4j` `FastAPI` `React` `Docker`

### 🛡️ [Real-Time Fraud Scoring Service](https://github.com/AshokSingodia-Codes/fraud-scoring-service) · [Live dashboard](https://fraud-scoring-service.vercel.app) · [API docs](https://fraud-scoring-service.onrender.com/docs)
End-to-end fraud detection API on 590K IEEE-CIS transactions.
- LightGBM with time-based holdout and isotonic calibration: **0.91 ROC-AUC**, 0.55 PR-AUC, 59.7% recall at the top 5% of alerts
- Cost-based APPROVE / REVIEW / BLOCK decisions and top-5 SHAP reason codes per prediction
- API-key auth, rate limiting, PostgreSQL audit log, Prometheus + Grafana, Docker Compose, GitHub Actions CI/CD
- `LightGBM` `SHAP` `FastAPI` `PostgreSQL` `Docker`

### 🏭 [STEELSCAN: Industrial OCR Platform for Steel Coil Identification](https://github.com/AshokSingodia-Codes/steelscan)
Built during my internship at **JSW Steel (Dolvi Works)** to read circular coil-identification codes on the plant floor.
- OpenCV preprocessing (deskew, circular unwarping, contrast enhancement) feeding PaddleOCR and EasyOCR
- FastAPI backend with OAuth2/JWT, RBAC, full scan audit trail, CSV import/export and metrics endpoints
- React + Tailwind kiosk dashboard with live camera, upload and manual-override modes
- `OpenCV` `PaddleOCR` `FastAPI` `React` `SQLAlchemy`
